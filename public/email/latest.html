  1. Functional Subnetwork Localization for Efficient Continual Learning in Large Language Models
    提出 Function-isolated Memory-Efficient Optimization（CiMEO），先用梯度归因定位功能子网络，再将每个训练样本路由到相应子网络，仅更新选定区域的参数和优化器状态。在 140 万条顺序指令及五个生成式基准上报告了较高平均性能，并分析了子空间重叠与主角度。
  2. Rubric Judgments Lack Uncertainty: Conformal Weighting for LLM Evaluation
    提出 Uncertainty-aware Rubric Weighting（URW），用 conformal calibration 估计评分规约各标准的判断不确定性，再通过 split-conformal p-values 生成带覆盖保证的标准权重。实验显示其能提升成对偏好准确率和后续 RL 对齐效果。
  3. Bias Control and Injection for Multi-Agent Aggregation
    研究多智能体聚合中的非语义偏差，提出测试时聚合框架：对不同答案展示风格归一化的推理轨迹，并将初始选择置于少数位置以注入偏差、观察决策不稳定性。该方法在三个数学推理基准和四种异构 LLM 组合上报告了更高准确率与更高 token 效率。
